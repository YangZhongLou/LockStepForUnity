# 实现进度

## 实现顺序 (7 阶段)

```text
P1: 定点数学库 ───────────────────────────────────── (无依赖)
P2: 工具类 (VarInt, BufferPool, Log) ─────────────── (→ P1)
P3: 指令层 ──────────────────────────────────────── (→ P1)
P4: 传输层 ──────────────────────────────────────── (→ P2)
P5: 仿真层 ──────────────────────────────────────── (→ P1, P3)
          │
    P3/P4/P5 可并行
          │
          ▼
P6: 会话层 (核心) ────────────────────────────────── (→ P3, P4, P5)
          │
    ┌─────┴─────┐
    ▼           ▼
P7: 一致性层   回放/观战层 ───────────────────────── (→ P6)
```
