# 测试计划

每阶段有对应测试文件，位于 `Tests/` 目录。测试同时作为使用示例。

## 测试运行方式

```bash
dotnet run --project Tests
```

## 测试基础设施

`Tests/` 为独立 console 项目，无外部测试框架依赖。使用简单断言：
- `Assert(bool, msg)` — 失败时打印行号和消息
- `AssertEqual<T>(T, T, msg)` — 值比较

每文件含一个 `Run()` 入口，由 `Program.cs` 统一调用。
